# Учебный проект

Реализация aлгебраических алгоритмов на C++ с системой тестирования.

## Структура проекта
```
Algebra/
├── src/ # Исходные файлы
│ ├── main.cpp # Главная программа
│ ├── fib.cpp # Алгоритмы Фибоначчи
│ ├── pow.cpp # Алгоритмы возведения в степень
│ └── primes.cpp # Алгоритмы поиска простых чисел
├── headers/ # Заголовочные файлы
│ ├── matrix.h # Класс матрицы
│ └── test.h # Система тестирования
├── Tests/ # Тестовые данные
└── report/ # Отчёты
  └── report.md # Полный отчёт с анализом

```
